## A Web: de onde veio?

| Versão | Apelido | O que mudou |
|--------|---------|-------------|
| **Web 1.0** | Somente Leitura | Páginas estáticas, só consumo |
| **Web 2.0** | Leitura + Escrita | Redes sociais, conteúdo dinâmico |
| **Web 3.0** | Descentralizada | Blockchain, IA, controle do usuário |
| **Web 4.0** | Hiperconectada | IoT, IA avançada, automação |

---

## Como a web funciona?

Quando você entra em `google.com`…

1. Seu navegador faz uma **requisição**
2. Ela viaja até um **servidor**
3. O servidor envia uma **resposta**
4. O navegador **renderiza** a página pra você

---

<!-- _class: center -->

# Tudo na web é:

## Requisição → Resposta

Protocolo: **HTTP / HTTPS**

---

## O que é HTTP e HTTPS?

- **HTTP** — define como navegador e servidor trocam dados
- **HTTPS** — versão segura, com **criptografia SSL/TLS**
- **TCP/IP** — transporta os dados em pacotes pela rede

---

## O que os devs constroem?

| Área | O que é | Tecnologias |
|------|---------|-------------|
| **Frontend** | O que o usuário vê | HTML, CSS, JavaScript |
| **Backend** | Motor oculto, regras de negócio | Node, Python, Java, PHP |
| **Banco de dados** | Onde os dados ficam | PostgreSQL, MongoDB |
| **Full-Stack** | Domina tudo acima | Tudo junto 🚀 |
